# Lorrana Bruna

Site institucional da cantora gospel Lorrana Bruna, criado com React, TypeScript e Vite.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

A miniatura do lançamento usa a imagem pública do vídeo indicado no YouTube. Os dados biográficos e de agenda devem ser ajustados quando a equipe fornecer informações oficiais.
